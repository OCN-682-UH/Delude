Building a function to easliy count and sort taxonomic observations, returning the resulting dataframe

Show code 
#making a function that extracts a count of a certain subset of taxonomic data

#data = your original data frame, x = the taxonomic observation <chr>
phycount = function(data, taxa) { 
  df <- data |>
    select({{taxa}}) |>
    drop_na() |>
    group_by({{taxa}}) |>
    summarize(member_count = n()) |>
    arrange(desc(member_count))
    return(df)
}

Plotting functions

Show code 
taxonplot = function(df, taxa) {
      
  to_ggplot <- phycount(df, {{taxa}})
                #Nested function finally works!!! Hooray!!
  
  to_plotly <- ggplot(data = to_ggplot, aes(
          x = {{taxa}},
          y = member_count,
       fill = {{taxa}})) +
      geom_col() +
      theme( 
            axis.text.x = element_blank()) +
      #guides(fill = "none") +
      labs(y = "Member Count",
           )

ggplotly(to_plotly)
    
}

taxonplot() will quickly visualize the disparity in observations based on the taxonomic level you throw to it.

Extra useful that it reads the same variables as phycount() so if you know one you can do the other.
